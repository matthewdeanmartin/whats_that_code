Under the hood / 01

Several clues.
One informed guess.

Code can be ambiguous. The detector combines independent signals through ranked-choice voting so a single keyword does not have to carry the decision.

01 / METADATA
.py

Start with context

File extensions, shebangs, tags, and surrounding text can give the classifier a strong lead.

02 / CONTENT
{ }

Read the snippet

Keywords, syntax patterns, and optional parser checks add evidence from the code itself.

03 / ELECTION
↗

Combine the votes

Methods rank their candidates. The ensemble returns a lower-case language name or None when it cannot decide.

In practice / 02

From snippet to signal.

A direct call fits into an ingestion pipeline, a documentation tool, or any workflow that needs an approximate label.

● ● ●detect.pyPython API
from whats_that_code.election import guess_language_all_methods

code = "def greet(name):\n    return f'hello {name}'"

language = guess_language_all_methods(
    code,
    file_name="greet.py",
)

# "python"
print(language)
INPUT → OUTPUT

Give it the clue you already know.

The filename supplies an extension; the snippet supplies syntax. You can also pass tags, surrounding text, and prior language guesses through the Python API.

Know the limits / 04

A guess is a starting point.

Short or ambiguous snippets are difficult to classify, especially without context. Results improve when you can supply a filename or tags. Parser checks are optional, and native grammar availability depends on your Python environment.
